# Chat Bro — النسخة المعدلة

تتضمن هذه النسخة إصلاحات للمصادقة، كتالوج النماذج، تشغيل النماذج المحلية، وإرسال الصور والملفات.

## أهم التعديلات

- حذف شاشة ومسار **مساحة العمل** القديمين من التطبيق.
- تبسيط شاشة الرئيسية وتقليل ازدحامها مع الحفاظ على الوصول السريع للمحادثة والنماذج.
- إضافة اختيار صورة من الجهاز، واختيار ملفات PDF وملفات النص وJSON وZIP من شاشة المحادثة.
- تمرير الصور بصيغة `image_url` والملفات بصيغة `file_url` إلى نموذج الخادم المتوافق، مع رسالة واضحة عند استخدام نموذج محلي لا يدعم الرؤية.
- إصلاح تسجيل الدخول على أندرويد بإزالة فحص `canOpenURL` المضلل؛ يبقى نجاح OAuth معتمدًا على ضبط عناوين البوابة والخادم ومعرّف التطبيق في بيئة البناء.
- تثبيت قائمة النماذج السحابية على IDs متحققة من كتالوج الخادم الحي: GPT-5 Nano/Mini/5/5.5 وGemini 3 Flash وGemini 3.1 Pro.
- إضافة نماذج Ollama محلية مع تصنيف الاستخدام: محادثة، بحث، برمجة، ورؤية. حالة التثبيت تُقرأ من `/api/tags` ولا تُعرض كنجاح وهمي.

## تشغيل الخادم

```bash
pnpm install
pnpm start
```


## بناء Android

```bash
cd android
```


> ملف المفاتيح الذي كان موجودًا في الأرشيف الأصلي لم يُنسخ إلى أرشيف المشروع المعدل حفاظًا على السرية.

### تحديث أمني وتشغيلي إضافي
هذه النسخة لا تحذف أي نموذج من الكتالوج. تم تشديد حماية المحادثة وتنزيلات Ollama، إضافة تحديد معدل الطلبات، تحسين تحقق جلسة الدخول على Android، إصلاح إعدادات Cookie المحلية، إضافة فحص صحة حقيقي لـOllama، وإضافة جداول قاعدة بيانات أولية للمحادثات والرسائل والاستخدام والمرفقات. كما تم إصلاح ملف splashscreen التالف الموجود في الأرشيف الأصلي.
