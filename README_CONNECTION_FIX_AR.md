# إصلاح اتصال الخادم في Chat Bro

تم تعديل التطبيق ليمنع مشكلة «تعذر اتصال الخادم» الشائعة أثناء التطوير المحلي.

- في Android/Expo يتم استخدام عنوان المضيف الذي تعلنه Metro بدل `127.0.0.1`، لأن `127.0.0.1` داخل الهاتف يشير إلى الهاتف نفسه.
- في محاكي Android يستخدم التطبيق `10.0.2.2:3000` عند عدم توفر عنوان مضيف.
- في الويب، إذا كان Metro على المنفذ 8081، يحاول التطبيق استخدام API على 3000.
- يمكن فرض العنوان يدويًا عبر `EXPO_PUBLIC_API_BASE_URL`.
- طلبات tRPC تعيد المحاولة تلقائيًا حتى 3 مرات مع مهلة 60 ثانية لإتاحة وقت إيقاظ خدمة Render المجانية.
- أضيف فحص `/api/health` داخل الإعدادات لمعرفة حالة الخادم وزمن الاستجابة.
- الإصدار الإنتاجي يستخدم `https://chat-bro-2-1.onrender.com` افتراضيًا، مع بقاء `EXPO_PUBLIC_API_BASE_URL` متاحًا للتطوير المحلي.

## تشغيل محلي

1. شغّل خادم API على المنفذ 3000.
2. شغّل Expo/Metro.
3. إذا كان الهاتف والحاسوب على نفس الشبكة ولم ينجح الاكتشاف التلقائي، ضع عنوان الحاسوب المحلي في `.env`:

`EXPO_PUBLIC_API_BASE_URL=http://عنوان-الحاسوب:3000`

4. افتح الإعدادات واضغط «فحص» تحت «اتصال الخادم».

## Ollama

عند استخدام Docker، يشغل `docker compose up -d` خادم Ollama وخادم Chat Bro، ويصل API إلى Ollama عبر اسم الخدمة `ollama:11434`.
