# Chat Bro

منصة عربية متعددة النماذج مبنية بـ Expo وReact Native وNativeWind، مع خادم مستقل عبر tRPC وLLM المدمج.

## التغييرات الحالية

- تبدأ الدردشة برسالة ترحيب من مساعد Chat Bro العام؛ يرسل المستخدم أول رسالة ويحصل على رد، ثم يواصل معه أو يختار نموذجًا آخر من الشريط العلوي لفتح سجل مستقل.
- جميع النماذج الموجودة في `shared/chatbro-catalog.ts` تظهر في شريط الاختيار داخل الدردشة.
- لكل نموذج سجل مستقل محفوظ محليًا عبر AsyncStorage، فلا تختلط محادثة نموذج مع نموذج آخر.
- شريط الكتابة يستخدم `KeyboardAvoidingView` ويرتفع تلقائيًا فوق لوحة المفاتيح، مع إزالة زر المرفقات الوهمي والأزرار غير المنفذة.
- تسجيل الدخول من بطاقة الملف الشخصي يستخدم OAuth الحالي. إذا كان Google مفعّلًا في بوابة OAuth فسيظهر هناك دون وضع Client ID أو سر داخل APK.
- مفاتيح LLM وقاعدة البيانات والجلسات تبقى في بيئة الخادم فقط.

## النماذج المجانية والمحلية

أضيف إلى الكتالوج مجموعة موسعة من نماذج Ollama، ومنها Qwen وGemma وLlama وMistral وPhi وDeepSeek وQwen Coder وCode Llama وStarCoder2 وGPT-OSS ونماذج الرؤية. هذه النماذج لا تحتاج مفتاح API، لكنها تحتاج تثبيت Ollama وتشغيل النموذج على خادمك، ثم ضبط `OLLAMA_BASE_URL`. يستخدم الخادم مسار Ollama المحلي المتوافق مع `/api/chat` ولا يرسل المفاتيح إلى الهاتف.

يوجد تبويب **محلي** مستقل في القائمة السفلية. زر **تنزيل** لا يضيف وزن النموذج إلى المشروع أو APK؛ بل يرسل طلب `ollama /api/pull` إلى مشغل Ollama الخارجي ليُخزّن النموذج على خادم التشغيل. أما النماذج الخارجية فتستخدم `MODEL_GATEWAYS_JSON`، بحيث تكون لكل بوابة قاعدة عنوان ومفتاح منفصلان على الخادم. يدعم ذلك Kilo وLLM7 أو أي بوابة OpenAI-compatible، دون خلطها مع Ollama.

المصادر التي تمت مراجعتها: [Ollama Library](https://ollama.com/library)، و[llama.cpp](https://github.com/ggml-org/llama.cpp) لتشغيل GGUF محليًا وواجهة OpenAI-compatible، و[Hugging Face Text Generation](https://huggingface.co/models?pipeline_tag=text-generation)، و[قائمة Free LLM APIs](https://github.com/mnfst/awesome-free-llm-apis). الخدمات العامة المجانية قد تفرض حدودًا أو تتغير، لذلك لا يعتمد التطبيق عليها افتراضيًا.

تم اختبار المسارات فعليًا: `smollm2:135m` عبر Ollama أعاد ردًا من خلال `chat.complete`، و`kilo-auto/free` عبر بوابة Kilo أعاد ردًا من خلال المسار المنفصل، و`gemini-3-flash-preview` عبر الخادم المدمج أعاد ردًا ناجحًا. أضيف حد إخراج و`repeat_penalty` ومهلة 45 ثانية لمنع تعليق الطلبات أو التكرار غير المنضبط. النماذج غير المحلية المدفوعة أو المحدودة تحتاج مفاتيح الخادم المهيأة في Render أو Docker.

## تشغيل واستضافة مستقلة

شغّل الخادم على خدمة مستقلة (مثل VPS أو Render أو Railway أو Fly.io) باستخدام `pnpm run build` ثم `pnpm start`. عرّف متغيرات `.env.example` في لوحة أسرار الاستضافة، واضبط `EXPO_PUBLIC_API_BASE_URL` في بيئة بناء التطبيق إلى عنوان الخادم الدائم. لا تستخدم روابط sandbox المؤقتة في الإصدار النهائي.

## الأمان

لا تُضمّن ملفات APK أو مفاتيح API أو ملفات إعدادات تحتوي أسرارًا في المستودع. تم تنظيف `.project-config.json` وإضافة `.env.example` بقيم فارغة. يجب تدوير أي مفاتيح ظهرت في أرشيفات أو إعدادات سابقة قبل النشر، لأنها تُعد مكشوفة.

## تحسينات Chat Bro الأمنية والتشغيلية في هذه النسخة
- حماية عمليات المحادثة وتنزيل نماذج Ollama بتسجيل دخول فعلي عبر `protectedProcedure`.
- إضافة Rate Limit داخل الخادم للمحادثات والتنزيلات، مع إبقاء النموذج والكتالوج كاملين دون حذف أي نموذج.
- التحقق من النموذج المطلوب مقابل الكتالوج قبل تمريره إلى الخادم، مع السماح ببوابات `gateway:*` المهيأة في الخادم.
- إضافة فحص صحة فعلي لـ Ollama عبر `/api/health/ollama`، وتحسين `docker-compose.yml` ليشغّل خادم Ollama مع تخزين دائم وفحص صحة.
- جعل منفذ Ollama مستمعًا محليًا على المضيف بدل تعريضه مباشرة للإنترنت، بينما يتواصل API معه داخليًا عبر شبكة Docker.
- تحسين CORS بحيث لا يعكس أي Origin عشوائيًا عند استخدام بيانات اعتماد/كوكيز.
- إصلاح كوكي الجلسة محليًا: HTTPS يستخدم `SameSite=None; Secure`، بينما HTTP المحلي يستخدم `SameSite=Lax` حتى لا يفشل تسجيل الدخول في بيئة التطوير.
- بعد تسجيل الدخول من التطبيق، يتم التحقق من المستخدم من `/api/auth/me` بدل الوثوق ببيانات ملف شخصي قادمة من deep link.
- إذا فشل التحقق من جلسة محفوظة على Android، يتم حذف التوكن والملف المحلي بدل إبقاء مستخدم قديم ظاهرًا على الواجهة.
- إضافة جداول أولية للمحادثات والرسائل والمرفقات وأحداث الاستخدام، لتكون قاعدة جاهزة للمزامنة السحابية والتقارير لاحقًا.
- إضافة migration باسم `drizzle/0001_chatbro_platform.sql`.
- إصلاح اختبار تسجيل الخروج المعطل وإضافة اختبار Rate Limit.

### تشغيل Ollama عبر Docker
```bash
docker compose up -d ollama api
```
بعدها يمكن تثبيت أي نموذج موجود أصلًا في كتالوج التطبيق من شاشة النماذج المحلية. الأوزان تحفظ في volume مستقل اسمه `ollama-data` ولا تدخل APK.

### ملاحظة أمنية
يجب تعيين `JWT_SECRET` حقيقيًا وطويلًا، وعدم استخدام قيمة افتراضية في الإنتاج. كذلك يجب ضبط `CORS_ALLOWED_ORIGINS` على عنوان واجهة الويب الفعلي.
