## حالة Render الفعلية

آخر فحص حي أعاد HTTP 200 من `chatbro-api.onrender.com`. **المهيأ حاليًا هو OpenRouter فقط**: `openrouter=true`، بينما `builtInLLM=false` و`anthropic=false` و`gateway=false`. أعاد كتالوج OpenRouter 464 نموذجًا. كما أن نقاط جلب قوائم النماذج للمسارات الثلاثة الأخرى لم تكن منشورة على الخدمة الحية عند الفحص.

تغييرات الخادم موجودة في أرشيف المشروع لكنها **لم تُنشر على Render**. لم أغيّر أي خدمة إنتاجية؛ خدمات Render المرتبطة بالمستودع تعمل بالنشر التلقائي من `main`، لذا لم أرفع التعديلات إليها ضمن تسليم APK/المصدر. لا توجد مفاتيح API في الأرشيف. لتفعيل المزودين الأربعة، أضف المفاتيح الناقصة في Environment Variables للخدمة المقصودة فقط، ثم اختر مسار نشر الخادم وتحقق من صحته.

| المسار | متغيرات الخادم |
|---|---|
| Manus/Forge | `BUILT_IN_FORGE_API_KEY` و`BUILT_IN_FORGE_API_URL` عند الحاجة |
| OpenRouter | `OPENROUTER_API_KEY` |
| Anthropic | `ANTHROPIC_API_KEY` و`ANTHROPIC_BASE_URL` اختياري |
| بوابات متوافقة | `MODEL_GATEWAYS_JSON` أو `MODEL_GATEWAY_BASE_URL` و`MODEL_GATEWAY_API_KEY` |

زر البحث يدوي؛ لا يُرسل نص المحادثة المحلية إلى الخادم. عند تشغيله في محادثة سحابية يُرسل السؤال إلى الخادم للبحث ثم تُمرّر خلاصة المصادر للنموذج. لم أرسل طلب بحث/توليد حيًا لتجنب استهلاك الرصيد.

## بناء المشروع مجددًا

المتطلبات: Node.js 22، pnpm 9، JDK 21، Android SDK Platform 36، Build Tools 36.0.0، NDK 27.1.12297006.

```bash
pnpm install --frozen-lockfile
cd android
./gradlew --no-daemon --max-workers=2 :app:assembleRelease -PreactNativeArchitectures=arm64-v8a
```

المخرج بعد البناء: `android/app/build/outputs/apk/release/app-release.apk`.
